# Pebrel 2.6.1

## English

### Added

- Add right-click context menus to the SFTP drawer for files, folders, and empty space, covering open, download, copy, paste, copy path, rename, new folder, upload, reload, and single/multi-item delete with confirmation.
- Support opening remote SFTP files in the system default application via a managed local temporary copy, watching for saved changes and prompting (or optionally auto-uploading) to sync updates back to the server.

### Improved

- Dock the left files/SFTP drawer header into the window title bar when using top session tabs on Windows/Linux and tighten top SFTP spacing to eliminate the large empty gap above the file list.
- Change the default terminal bell mode from visual+audible to audible-only and stop falling back to full-screen visual flashes when only audible bell is selected.

## 中文

### 新增

- 为 SFTP 展开区新增文件、文件夹及空白处右键菜单，支持打开、下载、复制、粘贴、复制路径、重命名、新建文件夹、上传、刷新及单选/多选确认删除。
- 支持使用系统默认应用打开远端 SFTP 文件：先下载到受管临时目录并在保存时监听文件变化，自动询问（或可选自动同步）是否上传更新回服务器。

### 改进

- Windows/Linux 顶部标签模式下，左侧展开栏顶栏嵌入标题栏左侧让位区并收紧 SFTP 顶部间距，消除文件列表上方的大片空白。
- 默认终端响铃模式改为仅声音，不再在按 Tab 无补全候选等触发响铃时默认全屏闪烁。
