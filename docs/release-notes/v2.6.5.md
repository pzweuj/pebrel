# Pebrel 2.6.5

## English

### Added

- Open the Ctrl+K session connector directly inside the main workspace on cold start (when no previous session is restored) instead of launching a default PowerShell tab, allowing immediate selection of SSH hosts, `cmd`, PowerShell, or WSL.
- Highlight background session tabs with an accent tint, edge bar, medium-weight title, and unread indicator dot whenever new unread terminal output arrives; switching to the tab clears the highlight immediately.

### Improved

- Remove the spinning activity icon from session tabs across both sidebar and top-tab layouts.
- Strengthen selected-row contrast in the SFTP file browser with an accent-tinted background, left selection bar, persistent border across light and dark themes, and medium-weight filenames.
- Use a green spreadsheet icon for `.xlsx`, `.xls`, `.xlsm`, `.xlsb`, `.xlt`, `.xltx`, `.xltm`, `.ods`, and `.numbers` files in SFTP instead of the blue generic document icon.
- Cancel SFTP path editing when clicking anywhere outside the path editor without blocking the clicked target, while keeping clicks inside the input or on the confirm button working normally.

## 中文

### 新增

- 冷启动软件（无待恢复历史会话）时不再默认打开一个 PowerShell 标签页，而是直接在主界面展示 `Ctrl+K` 连接器，方便快速选择打开 SSH、`cmd`、PowerShell 或 WSL。
- 后台会话产生新的未读终端输出时自动高亮对应标签页（主题色底纹、强调边条、加粗标题与未读圆点），切换回该会话后立即清除高亮。

### 改进

- 取消侧栏与顶部会话标签右侧持续旋转的加载图标。
- 强化 SFTP 文件列表中选中行的视觉区分度，增加主题色高亮底纹、左侧选中指示条、失焦仍可见的边框以及更清晰的选中文件名与大小对比度。
- 为 SFTP 中的 `.xlsx`、`.xls`、`.xlsm`、`.xlsb`、`.xlt`、`.xltx`、`.xltm`、`.ods`、`.numbers` 表格文件使用绿色表格图标，避免与蓝色的 `.docx` 文档图标混淆。
- 编辑 SFTP 路径时点击路径编辑区外任意区域自动取消编辑，且不阻断点击目标（如选中文件行或点击终端）；点击输入框内部或确认按钮仍正常编辑与跳转。
