# Pebrel 2.6.0

## English

### Added

- Highlight plain-text status keywords (`ERROR`, `Succeed`, `Warning`, `INFO`, `DEBUG`, `OK`, and related terms) in terminal output using each theme's ANSI palette and contrast rules, without overriding explicit application colors or alternate-screen TUI apps.

### Fixed

- Prevent top session tabs from overlapping the left-docked files/details drawer and its resize divider; tabs now shift smoothly with the drawer width and adjust overflow scrolling bounds accordingly.

## 中文

### 新增

- 为所有内置与自定义主题新增终端纯文本状态关键词语义着色（如 `ERROR`、`Succeed`、`Warning`、`INFO`、`DEBUG`、`OK` 等），遵循各主题调色板与对比度规则，不覆盖程序显式 ANSI 配色，也不影响备用屏幕 TUI 应用。

### 修复

- 修复顶部会话标签与停靠在左侧的展开栏及其分隔拖拽条重叠的问题，顶部标签随左侧展开栏宽度同步让位，并同步更新溢出滚动边界。
