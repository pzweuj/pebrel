# Pebrel 2.6.3

## English

### Fixed

- Fix intermittent SFTP download and "Open with default application" failures when a pooled SSH connection becomes stale or reaches the server's concurrent channel limit (`MaxSessions`): opening an SFTP channel now evicts only the stale or saturated pool entry and reconnects without interrupting existing terminal panes.
- Fix intermittent SFTP download timeouts and handle exhaustion on slower, VPN, or jump-host links by reducing concurrent download handles from 64 to 16, extending the per-request timeout from 30 s to 60 s, explicitly closing remote handles after reads, and automatically falling back to single-handle sequential recovery when a concurrent segment read fails.

## 中文

### 修复

- 修复复用的 SSH 连接池会话假死或触及服务端并发通道上限（`MaxSessions`）时，SFTP 下载与「用默认应用打开」偶现失败的问题：建立 SFTP 通道失败时自动驱逐失效/饱和的连接池条目并重连，不中断已有终端会话。
- 修复慢链路、VPN 或跳板机环境下 SFTP 下载偶现超时及句柄计数泄漏的问题：将并发下载窗口从 64 收敛至 16、单请求超时从 30 秒放宽至 60 秒、读取结束后显式关闭远端句柄，并在并发分段读取失败时自动降级为单句柄顺序补传剩余数据。
